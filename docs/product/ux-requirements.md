# UX要件定義

## 1. UX要件の全体方針

TOBEジャーニーマップを実現するために必要なUX要件を「UI要件」と「コンテンツ要件」に分類して整理する。

---

## 2. UI要件

### 2-1. グローバルナビゲーション

| 要件 | 詳細 |
|------|------|
| UX-UI-01 | 課題・業種別に入れるセカンダリナビゲーションの設置 |
| UX-UI-02 | ヘッダーCTAに「無料相談」と「資料DL」の2択を設ける |
| UX-UI-03 | スマートフォンでの閲覧を前提とした縦スクロール設計 |
| UX-UI-04 | ナビゲーション項目は6項目以内、認知負荷を最小化 |

### 2-2. ヒーローセクション

| 要件 | 詳細 |
|------|------|
| UX-UI-05 | 3秒でビジネス価値が伝わるキャッチコピーとサブコピー |
| UX-UI-06 | ZERO-SaaS「初期費用0円」の数値訴求を最大化 |
| UX-UI-07 | ターゲットペルソナ別の入り口（中小企業・推進担当・パートナー）をファーストビューに設置 |

### 2-3. 信頼構築セクション

| 要件 | 詳細 |
|------|------|
| UX-UI-08 | 書籍・メディア掲載・登壇実績のロゴウォール表示 |
| UX-UI-09 | 顧客の声（テキスト+顔写真 or 会社ロゴ）の掲載 |
| UX-UI-10 | 開発実績数・対応企業数・支援年数などの数値インジケーター |

### 2-4. サービス説明

| 要件 | 詳細 |
|------|------|
| UX-UI-11 | 3サービスの違いを一覧比較できる比較テーブルまたはカード |
| UX-UI-12 | ZERO-SaaSは「月額費用シミュレーター」等インタラクティブ要素を設置 |
| UX-UI-13 | 各サービスの「こんな課題を持つ方へ」という課題起点の入口 |
| UX-UI-14 | 導入フロー（STEP 1〜5）の可視化 |

### 2-5. 事例・実績

| 要件 | 詳細 |
|------|------|
| UX-UI-15 | 業種タグ・課題タグでフィルタリングできる実績一覧 |
| UX-UI-16 | 各事例に「課題→解決策→効果」の3点セットで記載 |
| UX-UI-17 | 稟議用途を想定したPDF形式の事例資料ダウンロード |

### 2-6. 段階的CTA設計

| 要件 | 詳細 |
|------|------|
| UX-UI-18 | 「資料DL」→「セミナー参加」→「無料相談」の3段階のCTAパス |
| UX-UI-19 | 各ページ末尾に関連CTAを配置（コンテキストCTA） |
| UX-UI-20 | 相談フォームに「事前ヒアリング項目」を設けて準備感を演出 |

### 2-7. パートナー向けLP

| 要件 | 詳細 |
|------|------|
| UX-UI-21 | パートナー制度専用のランディングページを独立設置 |
| UX-UI-22 | 報酬体系・制度条件を図解で明示 |
| UX-UI-23 | オンライン登録フォームの整備 |

## 3. コンテンツ要件

### 3-1. キャッチコピー・メッセージ

| 要件 | 詳細 |
|------|------|
| UX-CT-01 | 「伴走型」の意味を平易な言葉で説明するコンテンツ |
| UX-CT-02 | ZERO-SaaSの「なぜ初期費用0円にできるのか」を説明するFAQまたはコラム |
| UX-CT-03 | 「生成AIで何ができるか」を具体例で示すユースケース集 |

### 3-2. 実績・社会的証明

| 要件 | 詳細 |
|------|------|
| UX-CT-04 | 開発事例を最低5件、課題/解決策/効果の形式で掲載 |
| UX-CT-05 | 代表・チームメンバーのプロフィール（写真・経歴）を掲載 |
| UX-CT-06 | ComfyUIマスターガイド等の出版・登壇・メディア実績の掲載 |

### 3-3. 教育コンテンツ

| 要件 | 詳細 |
|------|------|
| UX-CT-07 | 「業務システム開発を依頼するときのチェックリスト」等の啓蒙コンテンツ |
| UX-CT-08 | AIコンサル費用相場・相談事例紹介コラム |
| UX-CT-09 | note記事との連携（最新記事をトップページに自動表示） |

### 3-4. 費用・プロセスの透明性

| 要件 | 詳細 |
|------|------|
| UX-CT-10 | ZERO-SaaSの月額費用レンジの目安を明示 |
| UX-CT-11 | 相談〜納品までのプロセスをタイムライン形式で図解 |
| UX-CT-12 | よくある質問（FAQ）を30問以上充実させる |

## 4. サイト構造提案（新規）

```
/                          トップページ
├── /services/             サービス一覧
│   ├── /co-dev/           伴走型システム開発支援
│   ├── /ai-consulting/    生成AIコンサルティング
│   └── /zero-saas/        ZERO-SaaS
├── /cases/                導入事例一覧
│   └── /cases/{id}/       個別事例詳細
├── /resources/            お役立ちコンテンツ
│   ├── /blog/             ブログ（note連携）
│   └── /downloads/        資料ダウンロード
├── /partner/              パートナー制度専用LP
├── /about/                会社概要・チーム紹介
├── /contact/              お問い合わせ（段階別CTA）
└── /faq/                  よくある質問
```
